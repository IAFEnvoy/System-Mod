# 多选一奖励

多选一是通用奖励内容 `system:choice`，通过现有 `Reward.contents` 接入签到、商城、奖池、成就、在线作业和分解产物，不另建一个玩法模块或奖励注册表。获得时将完整候选快照存入系统空间，玩家预览并确认后才生成选中产物；AI 不代替玩家确认选项。

## 数据定义

下面对象可直接放入签到奖励定义；其他奖励来源沿用各自的外层字段。字段里的名称可以使用翻译键字符串，字面量使用 Component 对象。

```json
{
  "label": { "text": "自选补给" },
  "contents": [
    {
      "content": {
        "type": "system:choice",
        "name": { "text": "补给二选一" },
        "icon": { "id": "minecraft:chest" },
        "options": [
          {
            "label": { "text": "矿物补给" },
            "items": [{ "id": "minecraft:iron_ingot", "count": 8 }]
          },
          {
            "label": { "text": "旅行补给" },
            "items": [{ "id": "minecraft:bread", "count": 16 }],
            "contents": [{ "content": { "type": "system:experience" }, "amount": 25 }]
          }
        ]
      },
      "amount": 1
    }
  ]
}
```

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `type` | Identifier | 必填 | `system:choice` |
| `name` | 翻译键 / Component | 必填 | 空间中显示的选择包名称 |
| `icon` | IconReference | 必填 | 选择包图标 |
| `options` | Reward 数组 | 必填 | 2～36 个非空选项，每项有 `label`，支持 `items` / `contents` 混用；禁止嵌套 choice |
| 外层 `amount` | 正 long | `1` | 独立选择次数；一次确认消耗一份，受空间预留容量限制 |

同一奖励中可混入固定产物和多个选择包。商城批量购买、连抽可累计选择次数，每份分别选择。离线签到仍按整包估值规则筛选，含选择包的奖励应显式配置 `offline_value`，不会自行用最便宜的选项推断价格。

## 操作

1. 在 `/space` 点击待选择的奖励包。
2. 选项卡片显示名称、图标和产物摘要，复用共享网格分页；图标 tooltip 显示完整产物摘要。
3. 点击选项只预览，点击“确认选择并存入空间”才永久确认。
4. 回到系统空间，通过现有取出流程领取物品、兑现系统币 / 经验或执行 action。

含未选择内容的旧“领取奖励”按钮会打开系统空间，不会自动选第一个选项，也不会先取出固定部分。简约模式保留有编号的预览与确认操作。卡片类型和资源模板均为 `system:reward_choice`，可由资源包覆盖。

## 状态与容量

选择回执、源选择次数扣除和全部选中产物在同一次玩家文件事务中保存。回执键为源条目 ID 与确认前的剩余次数；旧按钮重试、并发选择其他选项或重登后重放，均返回第一次选定的结果，不能再消耗下一份。新的一份必须重新打开空间取得新票据。

源奖励定义变更、删除或被禁用，不改写已获得选项。选中产物继承源奖励身份，部分取出后不会通过原奖励按钮重复发放；全部取完后仍保留选择回执。永久回执只保留选择包名称、选项序号和选中产物，不反复复制未选择的候选。永久回执受现有玩家业务文件体积上限约束，不自动淘汰为可重选。

空间在获得选择包时按“最大选项产物条目数 × 选择次数”预留容量；未支付 / 支付未知订单也占用预留，主动存物不能挤占这些位置。确认选项只更新空间，不直接修改 Minecraft 背包或执行动作；选择后的取出继续使用已有事务和 UNKNOWN 核对规则。

内容类型新增 `capacity` 元数据与 `prepareReward` 付款前校验钩子。普通内容默认占一个条目，默认付款前校验沿用 `prepare`；choice 独立校验每个选项，直接取出则要求先选择。扩展说明见[系统空间](system-space.md#新内容类型)与[通用奖励](rewards.md)。

开发示例位于 `src/test-mod/resources/data/system/system/signin_reward/test_choice.json`，只进入开发资源，不进入发布 JAR。
