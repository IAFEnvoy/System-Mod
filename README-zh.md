# System

[English](https://github.com/IAFEnvoy/System-Mod/blob/master/README.md) | 简体中文

把网文中的“系统”带进 Minecraft：一个帮助你处理任务、奖励、商城、传送和日常问题的助手。你可以操作交互卡片、输入请求，也可以直接与系统说话。许多功能无需
AI 即可使用。

## 功能概览

- **玩家与物品查询**：查看自身信息，按名称或提示文本搜索物品，浏览合成配方和材料获取方式。
- **任务与委托**：接取交付委托，查看要求、提交材料并领取报酬。安装 FTB Quests
  后，还可以按章节浏览其中的任务、提交目标并接收完成或解锁通知。固定任务后，可以在屏幕上持续查看进度。
- **系统空间**：保存奖励和主动存入的物品。点击取出一个，按住 Shift 取出一组，也可以通过语音取出。部分奖励可以从多个选项中选择。
- **商城与钱包**：购买补给、出售物品，管理多种货币。商城可以轮换库存、设置限购，或根据你的发展进度提供商品。
- **抽奖**：预览奖品、单抽或连抽、查看抽奖记录；整合包还可以设置保底奖励。
- **每日奖励与进度**：签到领取补给，获得连续签到和里程碑奖励，完成成就；登记收藏物品时不会消耗物品。
- **装备工坊**：查看手持装备的信息，预览费用和结果后进行维修或分解返材。
- **在线作业**：将采集或生产项目加入队列，提供所需材料并领取产物。离线时进度暂停。
- **传送锚点**：保存和重命名目的地，通过卡片或语音传送。服务器还可以提供公共目的地，并设置传送费用或限制。
- **对话与语音**：选择 AI 的参与程度，提问、自由聊天，或使用可选的语音输入和回复播报。
- **卡片与 HUD**：切换完整工作台和简约对话界面，选择主题，通过 Saturn 的 HUD 编辑器移动面板。熊猫头可以展示表情，并在说话时播放动画。
- **限时活动**：商城、奖池、签到奖励和委托可以在指定日期或时段开放，卡片会显示当前开放状态和下次开放时间。

实际提供的内容、奖励和限制取决于整合包或服务器。本地查询、浏览及上述内置玩法均可在不使用 AI 的情况下运行。

## 快速开始

1. 安装模组和 Assistant Core 等必需前置，然后进入世界。
2. 管理员使用 `/system grant system:default [玩家]` 为玩家绑定系统。单人游戏中省略玩家名即可给自己绑定。服务器和整合包也可以提供其他系统。
3. 输入 `/system` 打开助手。可以先尝试查看玩家信息、查询物品或浏览任务。
4. 通过侧边栏和卡片按钮体验功能。在系统界面输入 `/settings` 修改偏好，设置会自动保存。

使用 `/system full` 打开完整工作台，或用 `/system simple` 打开简约界面。你可以在 Minecraft 的按键设置中绑定“打开系统界面”，默认未绑定按键。

通知显示时，打开 Minecraft 聊天栏（**默认 T 键**）即可操作按钮。通知会保留到你完成操作或将其关闭。

## AI 模式

在消息输入框旁选择模式：

| 模式     | 行为                               |
|--------|----------------------------------|
| 离线     | 使用本地功能，不调用 AI；请求不明确时提供可点击的候选操作   |
| 标准（默认） | 优先使用本地功能，由 AI 辅助选择操作或支持需要 AI 的功能 |
| 扩展     | 优先尝试本地功能，无法匹配时进入 AI 对话           |
| 自由     | 由 AI 主导对话，并调用你有权使用的功能            |

服务器决定可用的模式。不可选项会置灰并说明原因；未配置可用模型时，仍可使用离线模式。购买等需要确认的操作会保留确认步骤。

### 启用 AI

单人玩家或局域网房主可以在 `/settings` 的“API Key管理”中添加服务商凭据，再到“文字交互”中选择。默认服务商为
DeepSeek，也支持其他兼容的服务商。

独立服务器的文字 AI 由服主配置。加入服务器的玩家使用服务器的配置，无法在客户端修改这些凭据。只有服务器启用后才可进行网络查询，回答问题时会先查本地资料。

## 常用指令

以下指令应在**系统界面的消息输入框内**输入，而非 Minecraft 聊天栏。你也可以使用自然语言或侧边栏，指令补全会显示当前可用的功能。

| 指令                    | 用途                |
|-----------------------|-------------------|
| `/help`               | 查看可用功能和帮助         |
| `/settings`           | 打开设置              |
| `/player`             | 查看自身信息            |
| `/quests [查询]`        | 浏览或搜索任务           |
| `/commissions`        | 浏览交付委托            |
| `/submittable [查询]`   | 查找可手动提交或勾选的任务     |
| `/claimable`          | 查找可领取的任务奖励        |
| `/space`              | 打开系统空间            |
| `/space_inventory`    | 选择背包中要存入的物品       |
| `/deposit [数量或stack]` | 存入主手物品；stack 表示一组 |
| `/records`            | 查看进度和里程碑奖励        |
| `/usage`              | 查看用量              |

## 可选语音

语音输入和自动播报默认关闭。在“API Key管理”中添加自己的凭据，再到 `/settings` 的“语音交互”中选择。支持 DeepSeek 和阿里云。

按住 **F8** 录音，松开后识别语音。可以选择将结果填入草稿或立即发送。语音请求会先尝试匹配当前通知的按钮，再发送到主对话。自动播报可以先试听后启用，通知音有独立开关。

语音凭据和用量保存在你的客户端，与服务器的文字 AI 分开。外部服务商可能对 AI 或语音服务收费，模组中的用量估算不能代替服务商账单。

## 服主与整合包作者

使用 `/system grant` 为玩家授予系统，使用 `/system module` 管理功能，使用 `/system ai` 控制 AI 权限和用量限制。
`/system ai default <模式>` 设置当前存档的默认模式和普通玩家可选模式的上限，玩家仍可选择更低的模式。

数据包可以自定义系统、委托、货币、商城、奖励和活动。资源包可以修改卡片布局、翻译、主题和头像贴图。这些配置共同决定玩家看到的内容。
