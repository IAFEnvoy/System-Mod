    添加节点

    编辑 Card JSON

    1. 载入内置模板，或打开 / 拖入项目内的 assets/<namespace>/cards/*.json。
    2. 用节点树选择、添加、复制、排序及删除节点；属性页与原始 JSON 双向同步。
    3. 在「上下文」里提供 parameters、states、callbacks。参数键保持平铺，例如 tasks.0.task_title；不是嵌套对象路径。
    4. {{id}}、{{tr:key}}、{{field:id}}、{{bool:id}}、{{state:id}}、循环中的 *、when / unless / repeat 均可预览。put 的默认状态会自动推导，states 中的值优先。
    5. 导出卡片只包含布局 JSON；导出工作文件同时保存示例数据、翻译和预览 CSS。工作文件可重新打开。
    6. 把导出的卡片放回资源包路径，再在游戏中重载资源。物品 / 玩家 / FTB 渲染、Saturn 数据、AUI CSS 和实际按钮逻辑需在游戏内检查。

    单文件，无外部依赖和 API 请求。有效编辑会尽力保存为此浏览器的本地草稿；file:// 的存储支持因浏览器而异，请及时导出工作文件。内置模板和语言表是随工具保存的快照，当前项目修改请通过「打开 JSON」载入。

    快捷键：Ctrl / ⌘ + S 导出卡片，Ctrl / ⌘ + Shift + F 格式化。文本框使用原生撤销；顶部撤销 / 重做回退有效的卡片版本。
