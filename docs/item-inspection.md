# 主手物品鉴定

鉴定属于已有的 `system:items` 模块，不另建模块。完整界面的物品工具栏提供“鉴定主手物品”，也可在系统对话框输入 `/inspect` 或 `/鉴定`。命令直接本地路由，不需要模型 API Key。

服务端在游戏线程读取主手的实际 ItemStack，返回名称、注册 ID、数量、堆叠上限、剩余/最大耐久、不可破坏状态，以及实际存储的附魔和附魔书内容。物品图标保留组件并使用原版 tooltip；卡片的“物品来源”按钮接入现有配方/掉落/tag 查询。空手会给出提示，不消耗物品。

这不是价值评估，也不推断模组的隐藏属性。附魔列表展示物品组件中的附魔，不推测临时增益。

| 入口 | 值 |
| --- | --- |
| 动作 / 卡片数据类型 | `system:item_inspect` / `system:item_inspection` |
| 只读工具 | `game.item_inspect`，同时提供给已授权的本地推理工具上下文 |
| 客户端模板 | `assets/system/cards/item_inspection.json` |

物品组件中的附魔、药水等可能引用数据包注册表。FileAgentStore 通过 `AgentStore.codec` 绑定当前世界的 RegistryOps；业务文件、聊天历史、大小估算、模型观察和写操作回执共用该上下文。网络继续使用已有的带注册表 StreamCodec。上下文随服务端存储实例创建和释放，不使用全局注册表缓存。
