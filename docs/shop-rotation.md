# 商城周期轮换

固定商城模块 `system:shop` 支持可选的 `server.rotation`，从该模块 `offers` 指定的固定池中选取本期库存。购买和收购分别选取、分别展示，仍可与其他模块[合并](module-merging-design.md)到同一个页面和卡片。省略该字段保留全部固定库存；内置默认商城不开启轮换。

## 模块定义

文件：`data/example/system/system_module/daily_shop.json`。

```json
{
  "order": 60,
  "icon": { "id": "minecraft:emerald" },
  "server": {
    "type": "system:shop",
    "offers": "#example:rotation_pool",
    "rotation": {
      "period": "daily",
      "count": 6,
      "per_player": false,
      "seed": 0
    }
  },
  "client": "system:shop"
}
```

`offers` 仍支持商品 ID、`#tag` 或混合数组，省略为全表、`[]` 为空。池内条目是现有的 `system:shop_offer`，商品和收购字段不变，见[数据包配置](datapacks.md)与[固定收购](shop-buyback.md)。在系统定义的 `modules` 启用这个模块后生效；不要同时启用另一个暴露同一完整池的固定模块，否则合并结果仍能看到它提供的非轮换库存。

| rotation 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `period` | `daily` / `weekly` / `monthly` | `daily` | 自然日、周一开始的自然周、自然月 |
| `count` | int，1～4096 | 必填 | 每个交易方向最多选取的不同条目数；不会重复抽同一条目 |
| `per_player` | boolean | `false` | false：同一世界、同一模块的启用玩家共用本期选品；true：加入玩家 UUID，个人选品 |
| `seed` | long | `0` | 数据包作者可设置的选品盐；不是世界种子，不能保证不同盐必定抽到不同结果 |

数量不足时展示实际条目数；购买和收购独立取最多 `count` 项。不支持 `lifetime`，不按游戏天数或距离服务器启动的固定秒数刷新。

## 稳定选品与刷新

周期使用服务端 `system-agent.json` 的 `timeZone`，与签到和商品限额的业务日历一致。每天当地零点、每周一当地零点或每月一日当地零点更新；夏令时按日历边界处理。

选品由世界种子、模块定义 ID、时区、周期、当前周期起点及配置盐确定；个人模式还加入玩家 UUID。相同世界与定义在同一周期内重复浏览、搜索、退出重进或重启服务器不会重新抽取。搜索词、物品候选和玩家当前是否满足商品条件不参与选品，先选库存，再执行原有条件与搜索过滤。某人看不到部分条件商品时不会自动补选其他条目；可见数量可能少于 `count`。

轮换卡片显示刷新时间、时区、共享／个人范围，并提供“刷新库存”按钮。界面保存查询快照，不定时重建卡片；刷新、重新浏览、报价和确认均取当前周期库存。共享仅指选品相同，付款与限购仍然按玩家独立计算。

## 报价、限额与订单

轮换库存的修订号包含周期，即使下期仍选中同一商品，旧周期报价也失效。服务端在确认和实际扣费前重检当前库存与修订号；过期卡片需要重新浏览／报价，不能支付下架商品。后台读取额度后如果库存恰好跨周期变化，游戏线程会拒绝该次旧快照，要求重新获取，不混用两轮库存的限额与无限来源去重结果。

商品 ID 和 Holder 不变，同一条目被多个固定模块选中只展示一次，共用原限额。合并修订号按完整来源版本集合生成，成员遍历顺序不会改变报价。已结算订单仍返回原权益，下架或刷新不会丢失待领取商品。

`rotation` 只控制上架选品，`purchase_limit` 独立控制每玩家可交易份数。每日轮换不会重置终身限额；每周限额也不会因为每天刷新而重置。固定池售罄后不会立即补选其他商品。

与 Evaluate 无限交易合并时，只有当前上架、可见、满足使用条件且额度未用完的固定商品会遮蔽无限来源；固定条目轮换下架或限额用尽后，无限来源可按原有 `hide_fixed` 规则重新出现。它仍然只在搜索时生成，见[无限交易](value-commerce.md)。

轮换通过确定性选品实现，不新增库存文件或数据包注册表。修改模块定义／商品定义需重开世界或重启服务端；修改候选池、盐、时区或世界种子会改变选择依据。
